# Análise de tendências e OS preditiva

A especificação vigente, o diagnóstico do código anterior, as regras de suficiência e persistência, os critérios configuráveis, a API, o ciclo de episódios/OS e os procedimentos de validação estão documentados em [Identificação de tendências](../IDENTIFICACAO_TENDENCIAS.md), revisão de 06/11/2026.

Esta revisão substitui as regras anteriores deste arquivo: o mínimo de leituras passou a ser configurável; desativação não herda outra configuração ativa; reduções podem ser configuradas como anormais; toda anomalia confirmada abre OS de inspeção. As migrações necessárias estão versionadas no repositório.
