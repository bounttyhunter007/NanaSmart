1.5 CRIAR: exportacao/utils/exporter_factory.py  [NOVO ARQUIVO]
------------------------------------------------------------------------

Propocito: Fabrica que recebe o formato ('csv', 'excel', 'pdf') e retorna
a instancia do exportador correto. Usa dicionario registrador.

O que deve conter:
  - Dicionario _EXPORTADORES mapeando string -> classe
  - Classe: ExportadorFactory
  - Metodo estatico: criar(formato: str) -> Exportador
  - Se formato invalido, levanta ValueError

Conteudo esperado:

  from .csv_exporter import ExportadorCSV
  from .excel_exporter import ExportadorExcel
  from .pdf_exporter import ExportadorPDF

  class ExportadorFactory:
      _EXPORTADORES = {
          'csv': ExportadorCSV,
          'excel': ExportadorExcel,
          'pdf': ExportadorPDF,
      }

      @staticmethod
      def criar(formato):
          cls = ExportadorFactory._EXPORTADORES.get(formato)
          if cls is None:
              raise ValueError(f'Formato desconhecido: {formato}')
          return cls()

      @classmethod
      def registrar(cls, formato, exportador_cls):
          cls._EXPORTADORES[formato] = exportador_cls

Beneficio do metodo registrar():
  - Para adicionar JSON no futuro, basta criar ExportadorJSON e chamar:
    ExportadorFactory.registrar('json', ExportadorJSON)
  - Nenhum if/elif precisa ser modificado.

2.1 CRIAR: gemini_api/prompt.py  [NOVO ARQUIVO]
------------------------------------------------------------------------

Propocito: Definir a classe Prompt, que e o PRODUTO final do Builder.
Encapsula a string do prompt em um objeto com semantica clara.

O que deve conter:
  class Prompt:
      def __init__(self, texto):
          self._texto = texto

      def obter_texto(self):
          return self._texto

      def __str__(self):
          return self._texto

      def __repr__(self):
          preview = self._texto[:80] + '...' if len(self._texto) > 80 else self._texto
          return f'Prompt({preview!r})'

Porque criar essa classe:
  - Atualmente os prompts sao strings soltas. Encapsular em Prompt permite
    adicionar validacoes futuras (ex: tamanho maximo, sanitizacao).
  - O Builder retorna um Prompt, nao uma string crua.
  - As views que chamam generate_content() passariam prompt.obter_texto()
    em vez de uma string direta.

  2. Classe concreta: PromptBuilderConcreto(PromptBuilder)
     Atributos internos:
       - self._blocos: list[str]  (acumula as partes do prompt)
       - self._max_linhas: int = 15  (limite para truncamento)

     com_contexto(self, context):
       Adiciona o bloco "CONTEXTUALIZACAO RAPIDA:" com os campos do context.
       Campos usados: company_name, total_equipment, active_equipment,
       maintenance_equipment, inactive_equipment, open_orders, unassigned_orders.
       Retorna self.

     com_alertas(self, alertas):
       Se alertas nao vazio, adiciona bloco "ALERTAS RELEVANTES:" com
       linhas truncadas (max 5).
       Retorna self.

     com_ordens(self, ordens, titulo="ORDENS EM ABERTO"):
       Se ordens nao vazio, adiciona bloco com titulo fornecido e
       linhas truncadas (max 5). O titulo configuravel permite reusar
       para "ORDENS ATRIBUIDAS", "ORDENS SEM ATRIBUICAO", etc.
       Retorna self.

     com_telemetria(self, dados):
       Se dados nao vazio, adiciona bloco "TELEMETRIA RECENTE:" com
       linhas truncadas (max 5).
       Retorna self.

     com_financeiro(self, dados):
       Adiciona bloco "CONTEXTUALIZACAO FINANCEIRA:" com total_cost,
       average_cost_per_os, completed_orders e top_equipment_costs.
       Retorna self.

     com_instrucoes(self, texto):
       Adiciona bloco "INSTRUCAO:" seguido do texto ou lista de textos.
       Retorna self.

     com_pergunta(self, texto):
       Adiciona bloco "PERGUNTA DO USUARIO:" seguido do texto.
       Retorna self.

     com_kpis(self, dados):
       Se dados nao vazio, adiciona bloco "KPIs DE EQUIPAMENTOS:" com
       linhas truncadas (max 5).
       Retorna self.

     build(self):
       Junta self._blocos com "\n" e retorna Prompt(texto_final).
       Chama self.reset() apos construir.

     reset(self):
       Limpa self._blocos = [].
